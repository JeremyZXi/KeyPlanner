# User Guide
This guide will help you understand how to use the main features of this Planner efficiently.
---
This todo app is designed for user following a particular school's schedule. In most of the cases, that school should have it's own cycle schedule apart from the regular week and month. This app can generate that letter schedule when provided a list of holiday from the school administrator. Likewise, one may also import a pre-assigned dates when onbording.
